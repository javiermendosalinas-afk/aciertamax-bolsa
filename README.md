# Bolsa Inmobiliaria Acierta Max · inmobiliaria.pro

Sitio aparte de acierta.pro (decisión de Javier, 5-oct-2026) con el inventario compartido de
NeoJaus (bolsa de AMPI, MIO, PAIS y Cámara de Comercio) en los 5 municipios de la ZMG.

- El inventario lo genera `herramientas/neojaus_sync.py` en el repo **acierta-pro-web**
  (`herramientas/neojaus/neojaus.json`); este sitio lo trae cada día con
  `herramientas/traer_bolsa.py` (workflow «Actualizar bolsa»).
- Front-end copiado de acierta.pro (buscador, ficha, mapa, comparador), sin blog, Pulso,
  simulador, proceso, Verifica ni portal de coaches. Nada enlaza a acierta.pro.
- Contacto: WhatsApp de Acierta Max (MAX) con la clave NJ-…; el portal de coaches de
  acierta.pro tiene «Buscar al originador por clave».
